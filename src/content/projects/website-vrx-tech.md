## Project context
VRX Tech asked for a simple, modern website that could present the company clearly without feeling heavy or overdesigned. I built the site with Angular and Tailwind CSS so the result would stay easy to maintain while still feeling polished and responsive.

The goal was to make the site readable at a glance, present the core services cleanly, and keep the experience smooth on mobile and desktop. I wanted the build to feel practical rather than flashy, with a layout that lets the content do most of the work.

![VRX Tech homepage placeholder](/images/projects/website-vrx-tech/homepage.png " ")

## Why Angular
I chose Angular because it fits structured, component-based projects well. The site is split into reusable pieces such as the navbar, hero section, content sections, and footer, which keeps the codebase organized and makes future edits easier.

Angular also gives the project a clear pattern for handling state and routing. For a company site, that consistency matters more to me than using a lighter framework with fewer conventions. I wanted a setup that would stay readable as the site grew.

## Why Tailwind CSS
Tailwind was a good fit for the visual layer because it let me move quickly without building a large custom stylesheet. Most of the layout, spacing, and typography decisions could be expressed directly in the template, which made iteration faster.

That approach also helped keep the design consistent. Instead of styling each component in isolation, I could keep the spacing rhythm and visual hierarchy aligned across the whole site.

![VRX Tech mobile layout placeholder](/images/projects/website-vrx-tech/phone-screen.png " ")

## Responsive layout
One of the most important parts of the build was making sure the site worked well across screen sizes. Using Tailwind's responsive utilities, I could tune the layout for mobile, tablet, and desktop without creating separate versions of the page.

That meant the navigation, content spacing, and section flow could adapt naturally instead of feeling squeezed or rearranged at the last minute. The final result stays readable and functional on smaller screens while still looking balanced on larger ones.

## Performance and maintainability
The site was also built with performance in mind. Angular's build optimizations and Tailwind's production CSS trimming help keep the final output lean.

Just as important, the structure is easy to maintain. The project is organized around reusable components, so future content changes or design updates should be straightforward.

## Outcome
The end result is a clean company website that feels modern, lightweight, and practical. It does not rely on a lot of extra visual noise, which makes it easier for visitors to focus on the information that matters.
